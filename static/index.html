Events (0)

When something happens, do something. Each event pairs a trigger with a list of actions.

Trigger Types

on_game_start — once, when the game boots
on_enter_room — the player enters a room
on_flag_set — a story flag is raised
on_item_pickup — an item is collected
on_hotspot_use — an object is used
on_dialog_end — a conversation ends

Action Types

set_flag / clear_flag — story flags
play_cutscene — run a cinematic
start_dialog — open a conversation
give_item — add to the inventory
unlock_door — open a locked exit
show_text — say a line
play_sound — play a sound effect
